# SnapFire v0.1.0 测试版

SnapFire 是一个面向真实场地的**混合现实（MR）真人枪战应用**：玩家各自捧着 Windows 笔记本，把摄像头当作枪口、屏幕当作瞄准镜，在真实房间里移动、瞄准、射击。

> 这是首个测试版。当前只实现「团战 → 巷战（室内）」模式；团战不是产品全貌，后续会扩展野战（室外）和其他真人枪战玩法。真实双机/真人现场验收尚未完成，建议小范围测试。

## 下载

- `SnapFire-0.1.0-win-x64.zip` — 便携版
- `SHA256SUMS.txt` — SHA256 校验值

## 运行

1. 下载 zip，解压到任意可写目录（例如 `D:\Games\SnapFire`）。
2. 双击 `SnapFire.exe`。
3. 首次启动会停留约 10 秒加载/预热本地识别模型。

- 无需 Node.js，无需安装，不创建桌面/开始菜单快捷方式。
- Windows 10/11 x64；需要摄像头。
- 数据保存在 `%APPDATA%\SnapFire\data`；删除解压目录不会删除战绩。
- 未签名测试版可能触发 Windows SmartScreen：点“更多信息 → 仍要运行”（仅在你信任来源时）。

## 快速开始

1. 首页 → 团战 → 巷战（室内）。
2. 房主点「创建房间」，记下 `IP:端口` 和 4 位房间号。
3. 其他玩家在同一局域网加入，输入地址和房间号。
4. 每人完成正面 + 背面建档；选择红队/蓝队。
5. 非房主点「准备」；房主确认开局检查后点「开始比赛」。
6. 空格 / 鼠标左键开火，Esc 离开本局。

详细说明见仓库 `README.md`。

## 当前能力

- 1V1 到 3V3，一房最多 6 人，红蓝自选
- 默认 5 分钟 / 10 杀；3~10 分钟 / 10~30 杀可调
- 统一伤害 25 血/枪，4 枪击倒
- 阵亡 5 秒后复活，复活后 2 秒无敌
- 队友不扣血；识别不确定时按未命中处理
- 结算、历史战绩、本地备份

## 已知限制

- 10 米处人脸通常不可用，主要靠衣着；逆光、暗光、相似服装会降低识别率。
- 当前为风格化占位 3D 美术，不是最终模型。
- 当前不做身体部位差异伤害、换弹/多武器、野战、登录/云/手机端。
- 无断线重连、正式安装包、自动更新、代码签名。
- 本地 JSON 未加密，请勿在公用电脑保存敏感照片。

## 校验

下载后可用 `SHA256SUMS.txt` 对照校验：

```powershell
Get-FileHash .\SnapFire-0.1.0-win-x64.zip -Algorithm SHA256
```
